# Claim Safety Checklist

Before posting results publicly, check:

- [ ] Do not claim full DFlash support unless an actual z-lab DFlash draft model runs.
- [ ] If using only a stub/block drafter, call it "DFlash-style" or "DFlash-inspired."
- [ ] Include exact model names and quantization.
- [ ] Include hardware.
- [ ] Include benchmark prompts or datasets.
- [ ] Include baseline numbers.
- [ ] Include limitations.
- [ ] State whether correctness was target-verified.
